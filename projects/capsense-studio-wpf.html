CAPSENSE™ Studio, WPF Edition

A native Windows reproduction of the capacitive-sensing tuning experience, with a built-in telemetry simulator so the full workflow runs without hardware.

Platform.NET 10, WPF, MVVM
My roleDeveloper
EmployerInfineon

The challenge

A tuning front-end already existed in Qt. The goal was a faithful native .NET version of the same experience that can be demonstrated, reviewed and tested anywhere, even when no sensing kit is connected.

What I built

  • A layered MVVM application in C# with declarative XAML, four custom controls and the Infineon Digital Design System look and feel (bundled fonts and the full colour-token set).
  • Zero third-party dependencies: no NuGet packages, which keeps the build hermetic and the attack surface small.
  • A transport abstraction (ITunerLink) with an end-to-end simulator as the shipped implementation. It models baseline tracking, Gaussian noise and automatic touch events.
  • Custom-rendered charts and a touchpad view drawn with DrawingContext, redrawn at about 30 frames per second from a rolling 300-sample history.
  • Live threshold editing, SNR measurement with a pass/fail verdict against a 5:1 criterion, and a projected touchpad X-Y view with centroid tracking.
  • Design-file reading and writing that patches files in place, byte for byte, with logic ported line by line from the Qt/C++ version.
  • Architecture documentation in Markdown and PDF with Mermaid diagrams.

Architecture

Outcomes

  • The complete workflow (discover, design, tune) is demo-ready with no physical kit.
  • A clean seam means a real serial transport can replace the simulator without touching the UI or view models.
  • A small, auditable code base: modern C# with nullable reference types and no external frameworks.
